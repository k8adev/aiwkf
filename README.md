Hi 👋🏻

I'm [Keit](https://x.com/k8adev), a programmer for 18 years. These days I spend most of my time pairing with AI agents while building a startup.

This is where I keep the agents, skills and everything I use to speed up, with AI, the work I already do. It's built mainly for Claude Code, but it also works with Codex.

It's a living repository that changes along with the way I work, so you can evolve your own day-to-day with AI alongside me.

## Plugins

**[agents](plugins/agents/README.md)** is a small team of five agents, organized by how much judgment the work needs, not by job titles like a real team, plus an `orchestrate` skill that tells you which one to call.
